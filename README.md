#💈 Senra Barber - Site Oficial

Este é o repositório do site oficial da **Senra Barber**, totalmente otimizado para dispositivos móveis (*Mobile-First*) e focado na conversão de novos clientes e agendamentos autônomos.

🔗 **Link do Site:** [https://senrabarber.com](https://senrabarber.com)

---

## 🚀 Funcionalidades
* **Design Otimizado:** Interface fluida e rápida focada 100% em smartphones.
* **Agendamento Autônomo:** Botão de chamada para ação (CTA) diretamente integrado à Página de Agendamentos do Google Agenda.
* **Portfólio Dinâmico:** Seção visual de "Antes e Depois" para demonstração de cortes e barbas.
* **Informações Rápidas:** Horários de funcionamento e localização de fácil acesso.

## 🛠️ Tecnologias Utilizadas
* HTML5
* CSS3 (Flexbox e Grid para responsividade)
* Google Agenda (Agendamento integrado)

## 📁 Como atualizar as fotos?
Caso queira alterar as fotos do Antes/Depois ou da Estrutura:
1. Adicione as novas imagens na pasta raiz do projeto.
2. No arquivo `index.html`, localize as tags `<img>` e atualize o atributo `src=""` com o nome do novo arquivo de imagem.
